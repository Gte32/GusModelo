# Proyecto Final - Sistema General de Personajes

Este es un sistema modular diseñado para la gestión y visualización de personajes de cualquier categoría.

## Arquitectura
- **Frontend**: PHP dinámico.
- **Backend API**: PHP RESTful.
- **Base de Datos**: MariaDB.

## Estructura
- api/
- database/
- frontend/

## Ejecución
```bash
docker-compose up -d --build
```
